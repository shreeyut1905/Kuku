How Promo Finder works

      
Editors used to watch every episode to hand-pick promos. This tool reads the timestamped scripts and hands them a ranked shortlist. AI makes the judgment calls; code handles everything that has to be exact.

      

        
1 · ReadCode parses every shot, action, sound and line with its start and end time, and gives each one an ID.

        
2 · FindThe AI reads each episode and picks promo moments by line ID. It never types a timestamp, so it can't invent one.

        
3 · FixCode converts IDs to exact times, enforces 20–60 s, never cuts mid-line, and snaps cuts to shot changes.

        
4 · JudgeA second AI pass sees only the clip, like a stranger scrolling: it scores the hook (first 3 s), the cliffhanger, and whether it makes sense on its own.

        
5 · RankCode ranks the clips, removes near-duplicates and adds warnings. The editor makes the final ✓/✗ here.

      

      
Checked against independent reviewers
On the free default model, blind reviewers (a different AI model) would post 8 of the top 10 and 70% of the top 30, against 22% of the bottom of the list. Stronger paid models separate even more sharply (about 85% against 6–11%). The tool's candidates included the reviewer's favourite moment in 47–49 of 50 episodes.

      
Built to swap models
Any OpenAI-compatible API works: one model to find candidates, another to judge, a fallback for content refusals, and a hard budget cap. The default runs on Qubrid's cheapest model, free.
